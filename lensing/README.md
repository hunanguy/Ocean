# The eddy's edge from stacked lensing of isolated galaxies

- `mistele2024_t1.txt`: Mistele et al. 2024, ApJL 969, L3, Table 1 (machine-readable; journal download).
- `edge_fit.py`: fits Eq. (15) out to an edge, with everything inside acting as one mass beyond it. `python3 edge_fit.py mistele2024_t1.txt 1000`
- Results: `edge-fit-results.md` in the claude.ai project (`claude/lensing/`).
