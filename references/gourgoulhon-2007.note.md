# Gourgoulhon — 3+1 formalism and bases of numerical relativity
Lecture notes, arXiv:gr-qc/0703035v1 (6 Mar 2007). Read 22 Nov 2026: Sections 6.2–6.6, 8.2.5, 8.3.3, 9.2.2.

**What it says that we use.**
- Eq. (6.95): for a conformally flat 3-metric γ = Ψ⁴f, the Laplacian of the lapse is D_iD^iN = Ψ⁻⁶ D̃_i(Ψ² D̃^iN). So the maximal-slicing lapse equation (9.15), D_iD^iN = N[4π(E+S) + K_ijK^ij], in vacuum at a moment of rest (K_ij = 0) is ∂·(Ψ²∂N) = 0: the paper's rule (a), with U = N and ψ = Ψ.
- §8.2.5 / §8.3.3: conformally flat, momentarily static (K = 0), vacuum data reduce the Hamiltonian constraint to the flat Laplacian ΔΨ = 0 (8.46, 8.109): the paper's rule (b). Solution Ψ = 1 + m/2r (8.111) and lapse N = (1 − m/2r)/(1 + m/2r) (8.117): Schwarzschild in isotropic coordinates (8.118, 6.24).
- §9.2.2: the standard Schwarzschild time slices are maximal, with lapse (9.16) as above.

**Use.** §11.7 (3.16): rules (a) and (b) are Einstein's vacuum equations in this slicing; cited so the paper says the geometry is reproduced, not newly derived (Fable, 22 Nov).
