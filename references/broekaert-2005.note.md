# Broekaert 2005 — verification note

**Citation.** J. Broekaert, "A modified Lorentz-transformation based gravity model confirming basic GRT experiments", Found. Phys. 35, 839 (2005) (confirmed by Arminjon 2006, ref. 40); arXiv:gr-qc/0309023 (v2). Read 21 October 2026 via alphaXiv: pp. 1–9, 13–14, 16. Full text not stored.

**Cited by.** W1, L1.

**What it gives.** A scalar model, after Sjödin, with a spatially variable speed of light and rods and clocks scaled to keep the locally measured speed invariant:
- rods: dx = dx′Φ; clocks: dt = dt′/Φ; light: c(r) = c′Φ²;
- masses: m ∝ Φ⁻³ (with the free parameter fixed by the Newtonian limit and the redshift);
- Φ = exp(−GM/c²r) from a Newtonian fit, satisfying a static field equation;
- the four classical tests (light deflection, perihelion precession, radar delay, redshift) reproduced at first post-Newtonian order for test bodies in a static spherical field;
- no black holes: c(r) vanishes only at r → 0.

**Bearing on 3.9 — significant.** This is W1 exactly. Light's coordinate speed ∝ Φ², rhythm and size each ∝ Φ, so each ∝ √c; inertia ∝ Φ⁻³ = c^(−3/2). W1's condition, including the inertia scaling, is Broekaert's (and Sjödin's) construction, published 2005. W1 must cite it as the precedent. What the Ocean adds is a medium-based reason (one substance, one speed) and, in W2, a candidate mechanism for Φ, with a light-speed law that departs from Broekaert's e^(−2u) beyond first order and vanishes at a finite radius.
